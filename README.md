## Featured work

> **Portfolio note:** The projects below are **training portfolio implementations** built in a GHL practice sub-account (Elite Home Renovations) using test or demo data. They demonstrate implementation skills. They are not presented as paid client deployments or independently audited savings.

**1. From site visit to supplier quote — GHL + n8n**
When a job reaches the site-visit stage, n8n checks the project details, matches active suppliers by trade and city, sends individual quote requests, then records the result and a follow-up task in GHL.
In the published LOOP test run, four matching suppliers were found, Gmail accepted four emails and there were zero send failures. *Accepted by Gmail does not mean delivered.*
→ [Published case study](https://loop.org.pk/student-projects/supplier-quote-request-automation-ghl-n8n/)

**2. Dashboards and reporting from a clean test dataset**
Seed demo opportunities safely, log each row's result, build role-specific dashboards, and reconcile totals to source data.

**3. Lead intake and follow-up**
Normalize incoming requests, route by service, prevent duplicate records, notify the right owner, and follow up with eligible leads.
